# AURORA Compressor

VST3-компрессор на JUCE 8 (C++17) с собственным GUI в стиле северного сияния.

## Сборка

Нужны: CMake ≥ 3.22, git, компилятор C++17 (Visual Studio 2022 / Xcode / GCC 11+). Все функции собираются из одного набора исходников, дополнительных зависимостей нет.
JUCE подтягивается автоматически через `FetchContent`.

```bash
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
```

Готовый `AURORA Compressor.vst3` (и Standalone для быстрой проверки) окажется в
`build/AuroraCompressor_artefacts/Release/`; после сборки плагин копируется в системную папку VST3.

## Параметры

| Параметр | Диапазон | Назначение |
|---|---|---|
| Threshold | −60…0 dB | порог срабатывания |
| Ratio | 1…20 (∞) | степень сжатия |
| Attack / Release | 0.1–100 ms / 5–1500 ms | скорость реакции (сглаживание в dB) |
| Knee | 0…24 dB | мягкость перехода |
| Makeup / Auto | −12…+24 dB | компенсация громкости |
| Mix | 0…100 % | параллельная (NY) компрессия |
| SC HPF | 20…500 Hz | фильтр сайдчейна (убирает «качание» от баса) |
| Detector | Peak / RMS | тип детектора |
| Output | −24…+12 dB | выходной уровень |
| Lookahead | Off / 1 / 2 / 5 / 10 ms | детектор «смотрит вперёд», звук задерживается; латентность сообщается хосту |
| Oversampling | Off / 2x / 4x | внутренняя обработка на повышенной частоте (FIR-фильтры, линейная фаза) |
| Sidechain | Internal / External | источник детектора; внешний сайдчейн включается в роутинге хоста |

## Новое в версии 1.1

- **Lookahead** — линия задержки по звуку, детектор видит сигнал без задержки. Плагин сам сообщает хосту
  латентность (lookahead + задержка оверсэмплера), так что компенсация задержки (PDC) работает автоматически.
- **Oversampling 2x/4x** — `juce::dsp::Oversampling`, FIR half-band, целочисленная латентность.
  Полезен при очень быстрых атаках и жёстких настройках.
- **Внешний сайдчейн** — у плагина есть вход Sidechain (моно/стерео). Выберите `Sidechain: External`
  и подайте сигнал в сайдчейн-вход плагина в вашей DAW. Если шина в хосте не включена, плагин
  автоматически использует внутренний сигнал. Фильтр SC HPF работает и для внешнего сайдчейна.
- **Пресеты** — 8 фабричных (видны хосту как программы) и пользовательские: кнопка SAVE, стрелки `<` `>` и выпадающий список.
  Пользовательские пресеты — XML-файлы в папке:
  - Windows: `%APPDATA%\Aurora Audio\AURORA Compressor\Presets`
  - macOS: `~/Library/Application Support/Aurora Audio/AURORA Compressor/Presets`
  - Linux: `~/.config/Aurora Audio/AURORA Compressor/Presets`

  Чтобы удалить пресет, удалите его файл из этой папки.
- **Масштабируемый GUI** — тяните правый нижний угол окна (пропорции сохраняются, 75%–200%);
  размер запоминается в проекте.

## Дизайн

- Фон: тёмно-синий градиент с тремя анимированными лентами «аврора» (бирюзовая, фиолетовая, розовая).
- Ручки: светящаяся градиентная дуга teal → violet → pink.
- Центр: передаточная кривая с живой точкой текущего уровня.
- Индикаторы IN / GR / OUT справа от графика.

## Идеи для развития

Мультидиапазонный режим, A/B-сравнение настроек, разные характеристики детектора («vintage»-режимы), удаление пресетов из GUI.
